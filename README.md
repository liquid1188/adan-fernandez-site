# Adán Alejándro Fernández — Official Website

One-page artist site for Dr. Adán Alejándro Fernández
(organist, harpsichordist, conductor, composer, writer).

## Structure

- `index.html` — the whole site: hero, recordings, biography, positions,
  selected performances, writing & scholarship, contact
- `assets/css/styles.css` — concert-program design system
- `assets/js/site.js` — header state, mobile menu (keyboard accessible),
  reveal-on-scroll, footer year
- `assets/img/` — photography (currently the artist's public press photos
  via Seven Eight Artists; swap in client-supplied files as needed)

## Content sources

Biography, positions, performances, and videos from the artist's
[Seven Eight Artists page](https://www.seveneightartists.com/fernandez).
Performance videos embedded from the artist's YouTube channel.
